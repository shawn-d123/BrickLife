Model lane: what's built, what's left

A borough-by-month forecast of London house-price growth, 12 months ahead, feeding the game through one JSON file and one chart. The model is done and handed off. What remains is mostly integration in the other three lanes.

Go / no-go GREEN · with a caveat

Error: across a six-year rolling backtest the point forecast beats all three baselines — MAE 0.041 vs persistence 0.062, London-trend 0.048, naive mean 0.069.

Caveat: up/down direction accuracy (60.5%) sits just under the majority-class rate (66%) and slips at turning points. So the pitch leads with the calibrated 80% interval and the borough decline probability, not the single number.

What's built

  • ✓Panel. 33 London boroughs × 375 months (1995–2026), 16 features. Bank of England Bank Rate fetched and merged, so the rate scenarios are a real model input.
  • ✓Baselines printed — B0 persistence 0.062, B1 London-trend 0.048, B2 naive mean 0.069. The idea-lock deliverable.
  • ✓Four LightGBM heads — quantile 0.1 / 0.5 / 0.9 plus a decline classifier, with the 80% interval conformalised so the band is honestly sized.
  • ✓Rolling-origin backtest, 2019–2024, 12-month embargo between every train and test block. Per-year and pooled metrics saved.
  • ✓predictions.json — 33 boroughs, is_stub: false, p10 ≤ p50 ≤ p90 on every row, growth as fractions. Validates against Contract §2.
  • ✓backtest.png in web/public/ — Hackney, model median vs actual vs persistence, shaded band. One panel, big fonts.
  • ✓Deterministic export — same three inputs produce a byte-identical file (checked by hash).
  • ✓README for D — the go/no-go sentence, the caveats, and the scenario_method wording for the "what's real" panel.
